# ANTECIPE V5
### Plataforma de Gestão, Validação e Antecipação de Recebíveis

Sistema web desenvolvido para importar, armazenar, consultar, validar e analisar recebíveis financeiros de maneira centralizada, utilizando Python, HTML, JavaScript e SQLite.

O Antecipe V5 foi criado para facilitar a análise de grandes carteiras de recebíveis, permitindo identificar documentos aprovados, barrados ou pendentes, consultar os motivos das decisões e estimar valores de antecipação.

A aplicação funciona localmente no computador e não exige instalação de Streamlit, Node.js, pandas ou outros frameworks externos.

---

# 1. Sobre o projeto

O Antecipe V5 oferece uma plataforma para gerenciamento de recebíveis, com foco em automação de importações, organização de dados, aplicação de regras e visualização de informações financeiras.

O sistema permite:

- Importar arquivos CSV, JSON e ZIP.
- Identificar automaticamente o conteúdo dos arquivos.
- Armazenar recebíveis em banco SQLite.
- Importar informações cadastrais de CNPJs.
- Registrar arquivos de pagamentos.
- Aplicar regras financeiras configuradas em JSON.
